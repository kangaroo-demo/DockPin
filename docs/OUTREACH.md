# DockPin distribution

- Repository: https://github.com/kangaroo-demo/DockPin
- English website: https://kangaroo-demo.github.io/DockPin/

The website is deployed automatically when its source changes. GitHub repository topics, About text, website links, and README calls to action provide consistent entry points. Search engine indexing is controlled by the search engines.
