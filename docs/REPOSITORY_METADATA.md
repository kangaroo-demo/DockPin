## Website deployment

The English and Chinese pages live in `docs/index.html` and `docs/zh/index.html`. The Deploy website workflow publishes `docs/` to GitHub Pages after changes are pushed to `main`. The app release version is independent of website updates.

The pages include canonical URLs, language alternates, social preview metadata, a software description for search engines, and a sitemap. These provide discovery metadata; search engine indexing and directory acceptance happen externally.
